# EventHub - College Event Management System

EventHub is a web-based college event management system that allows
students to discover and register for college events while admins
and coordinators can create, manage and monitor events.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

## Features

### Student
- Student registration
- Student login
- Student dashboard
- Browse events
- Event registration
- View registrations

### Admin / Coordinator
- Account registration
- Login
- Dashboard
- Create events
- Edit events
- Delete events
- View participants
- Department-based event management
- Event ownership
